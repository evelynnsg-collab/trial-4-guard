# TRIAL 4 GUARD

Aplicativo de estudos para formação e aperfeiçoamento de vigilantes patrimoniais.

## Recursos

- Cursos e trilhas de aprendizagem
- Manual do Vigilante Patrimonial
- Simulados interativos
- Acompanhamento de progresso
- Certificados

## Desenvolvimento

```bash
npm install
npm run dev
```

Projeto desenvolvido com Next.js, React e TypeScript.
